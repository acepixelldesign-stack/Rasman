# پوشه فونت فارسی اختصاصی پروژه (Custom Persian Fonts)

فایل فونت فارسی دلخواه خود را (با فرمت‌های `.woff2`، `.woff`، `.ttf` یا `.otf`) **مستقیماً داخل همین پوشه** قرار دهید:

`public/fonts/persian/`

## ویژگی‌های بارگذاری خودکار:
- **بدون نیاز به تغییر کد:** سیستم به‌صورت خودکار تمام فایل‌های فونت داخل این پوشه را شناسایی و بارگذاری می‌کند.
- **پشتیبانی از تک‌فایل و چندوزنی:**
  - اگر یک فایل فونت وریبل (مثلاً `IRANSansX-VF.woff2` یا `PeydaVF.woff2`) یا یک فایل عادی (مثلاً `Vazir.woff2`) قرار دهید، برای تمام وزن‌های متن و تیتر اعمال می‌شود.
  - اگر چند وزن جداگانه قرار دهید (مثل `Font-Regular.woff2`، `Font-Medium.woff2`، `Font-Bold.woff2` یا `300 / 400 / 500 / 700`)، وزن هر فایل از نام آن به‌صورت خودکار تشخیص داده می‌شود.
- **حالت پیش‌فرض:** در صورت خالی بودن این پوشه، پروژه از فونت پیش‌فرض فارسی (`Vazirmatn`) استفاده می‌کند.
