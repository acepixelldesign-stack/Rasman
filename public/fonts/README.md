# فونت‌های فارسی دلخواه (Custom Persian Fonts)

برای استفاده از فونت فارسی دلخواه خود (مانند ایران‌سنس، یکان‌بخ، پیدا، دانا و...) هیچ نیازی به تغییر کد نیست.

## آدرس پوشه آپلود فونت:
`public/fonts/persian/`

## فرمت‌های پشتیبانی‌شده:
- `.woff2` (بهترین و سریع‌ترین گزینه برای وب)
- `.woff`
- `.ttf`
- `.otf`

## نحوه استفاده خودکار:
1. فایل یا فایل‌های فونت فارسی دلخواه خود را داخل پوشه `public/fonts/persian/` قرار دهید.
2. پروژه به‌صورت خودکار تمام فایل‌های این پوشه را شناسایی کرده، وزن‌های فونت (`Regular`, `Medium`, `Bold`, `Variable/VF` و...) را تشخیص می‌دهد و روی نسخه فارسی سایت (`RTL`) اعمال می‌کند.
3. اگر هیچ فایلی داخل این پوشه نباشد، پروژه به‌صورت خودکار از فونت پیش‌فرض `Vazirmatn` استفاده می‌کند.

### نکته برای خوانش بهتر وزن‌ها:
- اگر یک فایل تکی یا فونت متغیر (`Variable / VF`) قرار دهید، برای تمام ضخامت‌ها اعمال می‌شود.
- اگر چند فایل با وزن‌های مختلف دارید، نام‌گذاری استاندارد فایل‌ها (مثل `Font-Regular.woff2`، `Font-Medium.woff2`، `Font-Bold.woff2`) باعث تشخیص دقیق هر وزن می‌شود.
